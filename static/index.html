How it works

01

Build text features

Each movie becomes four documents: overview, genres, top cast + director and keywords.

02

TF‑IDF vectorize

TfidfVectorizer turns every document into a sparse vector, weighting words that are frequent in one movie but rare overall.

03

Cosine similarity

cosine_similarity measures the angle between your movie's vector and every other — 1.0 means identical direction.

04

Blend & rank

"Everything" mode blends the four scores (plot 35%, keywords 25%, cast 20%, genre 20%) and returns the top matches.

Content-based filtering · scikit-learn · pandas · Data: The Movies Dataset (TMDB)
